# ProductCard

כרטיס מוצר בגריד: תמונה ביחס 4:5 על רקע לבן, בלי מסגרת, ומתחתיה שם ומחיר בשורה אחת. במעבר עכבר מוצגת התמונה הבאה של המוצר. זה הרכיב שהכי חוזר באתר.

- **תמונה:** יחס 4:5 על רקע `white`, **בלי מסגרת** (29.10.2026). צילום מוצר נכנס ב-`object-fit: contain`, בלי לחתוך
- **גלריה בכרטיס:** כשיש למוצר כמה תמונות, עד 5, אפשר לעבור ביניהן בלי להיכנס למוצר:
  - **במחשב:** במעבר עכבר מוצגת התמונה הבאה, וכשהעכבר יוצא התמונה הראשונה חוזרת. גם חצים מופיעים במעבר עכבר: ריבוע של 32px על `white`, עם מסגרת 1px ב-`line` שהופכת `black`, ופינות של 4px
  - **בטלפון:** מחליקים באצבע, והתמונה נעצרת בכל צילום
  - **נקודות:** 6px בתחתית התמונה, ב-`line`, והנקודה של התמונה הנוכחית ב-`black`
  - לחיצה על התמונה פותחת את המוצר. מוצר עם תמונה אחת נשאר בלי גלריה
- **שם ומחיר:** בשורה אחת בסגנון `product-name` (500): השם מימין, והמחיר משמאל בספרות טבלאיות. שם קצר ("כלום לא סתם"), והגזרה אחריו ב-· ("כלום לא סתם · קלאסי")
- **מבצע:** מחיר מקורי מחוק ב-`grey`, ולידו המחיר החדש
- **תגית:** לכל היותר אחת, בפינה הימנית העליונה (ראו Tag)
- **גריד:** 4 עמודות במחשב עם רווח 24px, ו-2 בטלפון עם רווח 12px. בעמודי קטגוריה, חנות ו-SALE כל המוצרים מוצגים בעמוד אחד, בלי "טען עוד" ובלי מספרי עמודים (29.10.2026)
