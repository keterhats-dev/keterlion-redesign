# ProductCard

כרטיס מוצר בגריד: תמונה ביחס 4:5 על רקע לבן, במסגרת דקה בבז', ומתחתיה שם ומחיר בשורה אחת. זה הרכיב שהכי חוזר באתר.

- **תמונה:** יחס 4:5 על רקע `white`, במסגרת 1px ב-`line` שהופכת `black` במעבר עכבר. צילום מוצר נכנס ב-`object-fit: contain`, בלי לחתוך
- **שם ומחיר:** בשורה אחת בסגנון `product-name` (500): השם מימין, והמחיר משמאל בספרות טבלאיות. שם קצר ("כלום לא סתם"), והגזרה אחריו ב-· ("כלום לא סתם · קלאסי")
- **מבצע:** מחיר מקורי מחוק ב-`grey`, ולידו המחיר החדש
- **תגית:** לכל היותר אחת, בפינה הימנית העליונה (ראו Tag)
- **גריד:** 4 עמודות במחשב עם רווח 24px, ו-2 בטלפון עם רווח 12px
