# ProductCard

כרטיס מוצר בגריד: תמונה מרובעת **על רקע לבן**, ומתחתיה שם קצר, שורת פרטים ומחיר. זה הרכיב שהכי חוזר באתר.

- **תמונה:** יחס 1:1, `object-fit: contain` על רקע `white`, ומסגרת 1px ב-`line` שהופכת `black` במעבר עכבר
- **שם:** קצר, בסגנון `product-name` ("כלום לא סתם", בלי "כובע… גזרה נמוכה… בצבע…"). הגזרה והקולקציה עוברות לשורת הפרטים ב-`grey`
- **מחיר:** בסגנון `product-name` עם ספרות טבלאיות. במבצע: מחיר מקורי מחוק ב-`grey`, ולידו המחיר החדש
- **עיגולי צבע:** 12px לכל צבע זמין
- **הוספה מהירה:** כפתור שחור בתחתית התמונה. במחשב הוא מופיע במעבר עכבר, ובטלפון הוא תמיד גלוי
- **תגית:** לכל היותר אחת (ראו Tag)
