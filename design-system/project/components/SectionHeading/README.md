# SectionHeading

ראש של אזור באתר: כותרת עליונה קטנה (eyebrow) אחרי פס זהב קצר, כותרת `h2` עבה, וקישור משני בצד השני.

- **כותרת עליונה:** בסגנון `eyebrow`, אחרי פס `gold` של 32×4
- **כותרת:** בסגנון `h2` (Heebo 900), כל הכותרת באותו עובי. אפשר לסיים בנקודה ב-`gold` ("נחלת בנימין 13, תל אביב.")
- **קישור:** משקל 700 עם קו תחתון של 2px ב-`gold` ("לכל הכובעים ←")
- האזורים מופרדים בקו של 1px ב-`line`, ולא בקו שחור
- על רקע שחור: הכותרת העליונה והפס ב-`gold`, והכותרת ב-`cream`
