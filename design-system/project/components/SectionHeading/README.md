# SectionHeading

ראש של כל אזור באתר: כותרת עליונה קטנה (eyebrow) עם קו קצר ב-`gold-deep`, כותרת `h2` במשקל 900, וקישור משני בצד השני. מתחת לכל זה עובר **קו שחור של 2px** לרוחב האזור.

- הכותרת קצרה ובשפה מדוברת ("מה חובשים עכשיו")
- הכותרת העליונה בטקסט `eyebrow`, בצבע `grey`
- הקישור בצד מקבל קו תחתון ב-`gold-deep` ("לכל המוצרים")
- על רקע שחור: הכותרת העליונה ב-`on-black-muted`, והקו הקצר ב-`gold`
