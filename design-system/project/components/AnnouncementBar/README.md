# AnnouncementBar

פס שחור דק (36px) בראש כל עמוד, מעל ההדר. הודעה אחת בכל פעם, מתחלפת כל כמה שניות, עם נקודה ב-`gold` מכל צד.

- ההודעות הן עובדות: "משלוח חינם בהזמנה מעל ₪249", "עיצוב אישי · גם כובע אחד", "משלוח לחו"ל ב-₪150", "החנות · נחלת בנימין 13"
- טקסט 13px בצבע `white`. החלק החשוב מודגש
- ההחלפה עוצרת אצל מי שהגדיר "הפחתת תנועה" (`prefers-reduced-motion`)
