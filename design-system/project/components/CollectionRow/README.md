# CollectionRow

שורה של קולקציה או קטגוריה: אות עברית, שם גדול וריבוע חץ שחור, בין קווים דקים בבז'. כמה שורות יחד יוצרות רשימה.

- **אות:** א׳, ב׳, ג׳... ב-16px במשקל 500, בצבע `grey`
- **שם:** בסגנון `category` (Heebo 500): 80px במחשב ו-34px בטלפון. שם ארוך ("כתרליון × נעמה אברהמי") קטן קצת בטלפון
- **חץ:** ריבוע 56×56 ב-`black`, עם ← לבן ופינה של `radius-sm` (בטלפון 44×44)
- **קווים:** 1px ב-`line` מעל כל שורה, וגם מתחת לאחרונה
- **מעבר עכבר:** הרקע של השורה עובר ל-`row-hover`
- כל השורה היא קישור אחד לעמוד הקולקציה
