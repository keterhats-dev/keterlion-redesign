# Button

כפתורים בגובה 56px עם פינה מעוגלת קלה (`radius-sm`, 4px) וטקסט `button`. בכל אזור יש רק כפתור ראשי אחד.

- **ראשי:** רקע `black` וטקסט `white` ("לכל הכובעים ←", "להתחיל לעצב · ₪100 ←")
- **מסגרת:** מסגרת 1px ב-`black` ורקע שקוף, לפעולה משנית ("עצבו כובע משלכם", "Google Maps")
- **על שחור:** רקע `white` וטקסט `black`. הפעולה האחת החשובה באזור (הצעת מחיר לעסקים, הרשמה למועדון) ברקע `gold` וטקסט `black`
- **ריבוע חץ:** 56×56 ב-`black` עם ← לבן, בסוף שורת קולקציה (ראו CollectionRow)
- **קישור טקסט:** משקל 700 עם קו תחתון של 2px ב-`gold` ("לכל הכובעים ←")
- בהדר הכפתורים בגובה 44px: "חיפוש" עם מסגרת, ו"סל (0)" שחור
- אין צל ואין "קפיצה" במעבר עכבר
