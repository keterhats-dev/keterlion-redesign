# Button

כפתורים מרובעים בגובה 50px, עם טקסט מודגש (`button`). יש שלושה סוגים, ובכל אזור מופיע רק כפתור ראשי אחד.

- **ראשי:** רקע `black` וטקסט `white`. לפעולה העיקרית ("הוספה לסל", "להתחיל לעצב")
- **מסגרת:** מסגרת 1.5px ב-`black` ורקע שקוף. לפעולה משנית ("פרטים נוספים", "Google Maps")
- **על תמונה או על שחור:** רקע `white` וטקסט `black`, ולצידו כפתור מסגרת לבנה
- אין כפתורים בזהב ואין פינות מעוגלות. קישורי טקסט מקבלים קו תחתון ב-`gold-deep`
