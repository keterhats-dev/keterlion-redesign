# כלי קונסולה ל-Elementor (staging)

אלה כלים שרצים בדפדפן, בעורך של Elementor או בעמוד באתר, כשמחוברים ל-staging. לפני שימוש שומרים כל קובץ ב-localStorage של הדפדפן, כי זה פר דפדפן ופר מחשב:

```js
localStorage.setItem('KLLIB', `...תוכן kl-lib.js...`)
eval(localStorage.getItem('KLLIB'))
```

| קובץ | מפתח ב-localStorage | מה הוא עושה |
|---|---|---|
| kl-lib.js | KLLIB | עזרים לבניית עמודי V4 (אטומיים) לפי סמטה: משתנים, כותרות, כפתורים, אזורים, גיבוי ושמירה |
| kl-restyle.js | KLRESTYLE | ממיר עמוד אטומי מ"סטריט חד" לסמטה |
| kl-fix-classic.js | KLFIX, KLOLDBORDER, KLSTEPS | מתקן רכיבים קלאסיים, מסגרות ישנות וסרגל השלבים בסל ובקופה |
| kl-scan.js | KLSCAN | רץ בעמוד באתר. מוצא שאריות של הסגנון הישן |
| kl-home-photos.js | (בלי מפתח) | מכניס את התמונות שלך למקומות השמורים בדף הבית 23950 |

- צבעי ה-Kit של Elementor (138) עודכנו לסמטה ב-26.10. משתני V4 נמצאים ב-kl-lib.js (V)
- פרמטר עוקף מטמון: לא להשתמש ב-?m= כי WordPress מפרש אותו כארכיון לפי חודש ומחזיר 404. משתמשים ב-?kl=1
