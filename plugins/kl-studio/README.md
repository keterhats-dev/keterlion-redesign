# KL Studio – כלי העיצוב האישי של כתרליון

תוסף וורדפרס שמחליף את Zakeke לכובעים. הלקוח בוחר גזרה וצבע, ואז רוקם בכל אחד מ-4 הצדדים (חזית, צד ימין, צד שמאל, מאחור): עיצוב מספר הרקמות, טקסט או לוגו שהוא מעלה. בסוף הוא בוחר כמות ומוסיף לסל הרגיל של WooCommerce.

## מאיפה הנתונים
- **הכובעים:** הווריאציות של "כובע מותאם אישית" (22544): Dad Cap ב-18 צבעים ובייסבול ב-8. המחיר והמלאי נקראים מ-WooCommerce בכל טעינה
- **תמונות 4 הצדדים ואזורי הרקמה:** מ-Zakeke (מוצר 10065158), נקראו ב-22.11.2026. התמונות נמצאות ב-`assets/caps/<וריאציה>-<צד>.jpg`. המרכז, הגודל המקסימלי והפיקסלים לס"מ של כל אזור נמצאים ב-`assets/data/cap-model.json`. הנתונים הגולמיים: `tools/studio/zakeke-sides.txt`
- **ספר הרקמות:** 67 העיצובים (SVG) ב-`assets/data/gallery.json`. 58 מהם בצבע אחד, ואותם צובעים לפי צבע החוט
- **המחירים:** בהגדרות (WooCommerce ← סטודיו עיצוב אישי). השרת מחשב כל מחיר מחדש בסל, ולא סומך על הדפדפן

## התקנה (ב-staging בלבד עד שהכול נבדק)
1. תוספים ← הוספת תוסף ← העלאת תוסף ← `kl-studio.zip` ← הפעלה
2. עמוד חדש, למשל "עיצוב אישי – חדש", עם הקוד הקצר `[kl_studio]` (באלמנטור: וידג'ט "קוד קצר"). עמוד מלא, בלי סרגל צד
3. WooCommerce ← סטודיו עיצוב אישי: לבדוק מחירים, ולהוסיף קישור לעסקים
4. LiteSpeed: התוסף מסמן את העמוד כ"לא לשמור במטמון". לבדוק שזה עובד (כותרת `x-litespeed-cache-control: no-cache`)

## בדיקה מקומית בלי וורדפרס
`dev/index.html` טוען את הכלי עם הנתונים האמיתיים, במצב הדגמה (לא שולח כלום). מריצים את השרת המקומי (serve.ps1, פורט 5502) ופותחים http://localhost:5502/plugins/kl-studio/dev/index.html

## מה עוד פתוח
- המחירים: לפי ההדמיה, ומחכים לאישור
- מידות האזורים בצדדים ובגב: חושבו מהמלבנים של Zakeke בקנה מידה אמיתי (Dad Cap: ימין 6.5×4.5, שמאל 5.5×3.5, גב 11.5×5. בייסבול: ימין 5.5×3, שמאל 6.5×4, גב 9.5×5). לאשר מול המכונה
- אזורי הרקמה מ-Zakeke. ב-Dad Cap אדום ושחור אזור החזית ב-Zakeke גדול יותר (21–22 ס"מ). בכלי הוא 14×6 בכל הצבעים. בבייסבול שחור אין ב-Zakeke אזורים בצדדים ובגב, ולכן לקחנו את האזורים של שאר צבעי הבייסבול
- הגופנים לטקסט: לבדוק שיש להם גופן רקמה מתאים
- טקסט נשמר בקובץ ה-SVG כטקסט (לא כקווים), ולכן תוכנת הרקמה צריכה את הגופן
